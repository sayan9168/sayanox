## Local increment: validated nested value replacement

`jd_set_raw` replaces an existing dotted-path value after validating both JSON
inputs, preserving the surrounding bytes and exact numeric text. Missing paths
and malformed inputs return an empty string. `jd_delete_raw` removes an
existing non-root value; `jd_object_put_raw` inserts or replaces a member of
an existing object using a JSON-encoded key. `jd_array_insert_raw` inserts at
a validated index in an existing array or appends at its length. Creation of
missing intermediate objects is supported by `jd_object_ensure_raw`; creating
missing arrays or inferring container types remains open. The expanded
hand-written boundary oracle passed
`./sx target test-stdlib-next` locally on seed-min, gen2 and native. This is
not fresh guarded complete CI or closure of R07.

## Local increment: bounded exact decimal arithmetic

`stdlib/decimal.sa` provides a separate string representation with exact
comparison, addition, subtraction, multiplication, rounded division and
half-away rounding for up to 256 digits. Invalid inputs, division by zero and
oversized results are refused. Hand-calculated boundaries and independent Python-decimal vectors
pass
`test-stdlib-next` on seed-min, gen2 and native. This increment is not complete
guarded CI or closure of R07.

## Local increment: exact decimal JSON updates

`stdlib/json_decimal.sa` reads and updates existing JSON numbers using the
bounded exact-decimal representation, preserving other source bytes and
rejecting malformed input, absent/nonnumeric paths and exponent notation.
Its independent boundary oracle runs on seed-min, gen2 and native through
`test-stdlib-next`. This does not close R07 or replace complete guarded CI.

## Local increment: CSV document tables

`stdlib/csv_table.sa` parses and writes multi-row CSV, validates packed frames,
updates cells, filters and projects rows with explicit byte/row/field caps.
The independent boundary and round-trip oracle passes `test-stdlib-next` on
seed-min, gen2 and native. This does not close stdlib depth or replace complete
guarded CI.

## Local increment: bounded CSV queries

`stdlib/csv_query.sa` provides stable joins, distinct, bytewise sorting and
exact decimal sums, means and grouping over CSV tables. Boundary, invalid-input
and cross-backend output oracles run through `test-stdlib-next`. This does not
close stdlib depth or replace complete guarded CI.
