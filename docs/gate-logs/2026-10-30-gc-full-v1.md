## Scope and remaining boundaries

This closes **current published-language v1 C-output self-host acceptance**;
accepted user programs are not narrowed to the pure-min compiler implementation
intersection. The published specification, inventories, oracles and gate
coverage were not weakened to obtain a pass.

Independent diverse-bootstrap trust proof remains **open**: an independently
bootstrapped reference compiler and externally reviewed provenance are still
required. Hashes, a same-anchor fixed point and the DDC harness controls are
not that proof. Full native-backend parity, future language proposals, precise
roots, arbitrary bounded-live-heap/RSS guarantees and leak-free execution are
not established. Existing sanitizer probes have leak detection disabled.
