## What changed

The maintained toolchain is now C, make, POSIX sh and Sayanox. No maintained
script, build recipe or exercised test path invokes bash, awk, sed, Python,
Perl, Node or Ruby.

- Six bash scripts were ported to POSIX sh.
- `tools/lsp_workspace_bind.awk` was replaced by
  `tools/lsp_workspace_bind.sa` (built by gen2). Its output on the real
  `tools/sayanox_lsp.sa` translation is byte-identical to the awk output
  (75,678 bytes) and it fails closed with a C `#error` on a shape change.
- The offline packer chunks with `split -b 1100`; `sed -n Np` line extraction
  is POSIX `read`; the IR-log invariant/vocabulary checks use
  `grep`/`cut`/`sort`/`paste`; emit-seam extraction uses `head`/`tail`; the
  512-entry generic-limit fixture is generated by the shell; the package
  wrapper uses `cut`/`tr`.
- Python was removed from the restore scripts (a dead installer branch and a
  base64 heredoc). It remains only in the optional HTTP/crawler test servers.
- The legacy sed-based `tools/sayanox-lsp.sh` server was deleted.

## What `test-language-deps` checks

1. **Static:** every tracked shebang script is `#!/bin/sh`; no recipe line in
   the Makefile invokes `awk` or `sed`; the old awk binder does not exist; the
   Sayanox binder and `split` chunking are in the build.
2. **Dynamic:** a PATH shim makes `bash`, `awk`, `sed`, `python3`, `python`,
   `perl`, `node` and `ruby` fail loudly and log any invocation. Under that
   PATH it regenerates the LSP translation and runs the Sayanox binder (then
   `cmp`s the result against the checked-in output), followed by `test-lsp`,
   `test-lsp-robust`, `test-native-ir-log`, `test-native-mem`, `test-seed-gc`,
   `test-seed-generics` and `test-sxpkg-online-local`. The shim log must stay
   empty.

Boundary, not overclaim: this exercises the maintained paths. The opt-in
Python HTTP/crawler tests are still Python, and the small hand-written C seed
plus the C native backend remain. No language semantics, generated C or
`gen3 == gen4` byte identity changed in this pass.
