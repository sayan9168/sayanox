# Native features

| Feature | Example |
|---------|--------|
| for loop | `for i = 1 to 10 { show i }` |
| break/continue | `when x { break }` |
| substr | `substr(s, 1, 3)` |
| string == | `when s == "hi"` |
| min/max | `min(a,b)` · `max(a,b)` |
| exit | `exit(0)` |
| ! / not | `when !a` |
| chr / ord | `chr(65)` |
| assert | `assert x > 0` |
| gc | `gc` · `gc_info()` |
