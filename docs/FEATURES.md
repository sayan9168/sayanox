# Native features

| Feature | Example |
|---------|--------|
| Comments | `// line` · `/* block */` |
| Logic | `not a` · `a and b` · `x or y` |
| Index | `s[i]` char code · `list[i]` |
| Assert | `assert x > 0` |
| Args | `arg_count()` · `arg(1)` |
| Functions | `make f(n) { give n*2 }` |
| Recursion | `fib(n-1)+fib(n-2)` |
| GC | `gc` · auto on pressure |
