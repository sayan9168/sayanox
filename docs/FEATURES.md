# Native features

| Feature | Example |
|---------|--------|
| break/continue | `when x { break }` |
| not / and / or | `when not a and b` |
| s[i] | `show s[0]` char code |
| chr / ord | `chr(65)` · `ord("A")` |
| assert | `assert x > 0` |
| gc / gc_info | `gc` · `show gc_info()` |
| make/give | recursive functions |
| arg | `arg(1)` · `arg_count()` |
