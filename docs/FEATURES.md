# Native features (complete)

| Feature | Example |
|---------|--------|
| for range | `for i = 1 to 10 { }` |
| for-in list | `for x in xs { show x }` |
| break/continue | `when x { break }` |
| export | `export name` |
| substr | `substr(s, 1, 3)` |
| string == | `when s == "hi"` |
| min/max/exit | `exit(0)` |
| gc / gc_step | incremental + full |
| modules | `use "lib.sa"` |
